# LuaLoader 1.9.0 UI 接口说明

基于本次上传的 LuaLoader-main(2)(2).zip 修改。保留本地 build.sh、CMake presets 和原版源码目录，同时保留 GitHub Actions 编译流程。

## 性能变化

- 图片首次绘制仍是按需加载，但每帧最多上传 2 个纹理；已上传一个后，累计超过 4 MiB 或帧内已耗时 5 ms 时，剩余上传推迟到后续帧。一次大 PNG 解码不能被中途暂停，所以这些是调度限制，不是硬性帧时间保证。
- 默认 32 MiB 估算缓存预算。桌面端计入基础 GPU 纹理、保留的 CPU RGBA 和裁剪纹理；Android 计入基础纹理。驱动内部副本、解码临时内存、游戏本身内存不在此预算内。
- 优先卸载至少两帧未使用的资源；图片 ID 保留，再次绘制时可重新加载。当前可见资源总量超过预算时，未装入的图片保持 pending，不继续无上限分配。
- 修复桌面裁剪纹理的独立释放，整图绘制不再复制一份裁剪纹理。
- 图片描述符最多 4096 项；同一 owner/path 再次请求直接查缓存，不再反复遍历文件路径。
- 固定文字字符串缓存最多 256 条，每条最多 512 字节；Android 使用 GC handle 保留，无法保留时回退到临时字符串。原生绘制指针缓存减少反射调用。

不需要改旧模组即可受益于缓存和调度。要避免上千条配方每帧循环，仍需模组使用下面的可见范围，只提交可见条目。PNG 文件压缩率不等于运行时内存占用；大背景建议缩至实际显示尺寸。

## 滚动接口

```lua
local sx,sy,vw,vh=mod.gui.begin_scroll("recipes",x,y,width,height,content_width,content_height)
-- 此处绘制坐标相对于滚动内容，加载器自动减去 sx/sy。
local first=math.max(1,math.floor(sy/row_height)+1)
local last=math.min(count,math.ceil((sy+vh)/row_height))
for i=first,last do
    -- 在 (i-1)*row_height 绘制第 i 项；只为这些项请求图片。
end
mod.gui.end_scroll()
```

支持手指/鼠标拖动内容、拖动右侧/底部滑轨，以及滚轮（游戏端 PlayerInput.ScrollWheelDelta 接口可用时）。滚动距离超过阈值后，取消本次按钮点击。各滚动区域用稳定 ID 保存会话内位置；切换页面后可恢复，但不保存到磁盘。`scroll_to(id,x,y)` 可回到指定位置。

坐标单位与已有 text_at/image/button_at 一致。内容尺寸必须显式提供；不要传无穷大或 NaN。所有 begin_scroll 必须配对 end_scroll，遗漏时加载器在回调结束自动收尾。

裁剪策略：矩形和 Android 图片按视口边界裁剪。游戏字体无法在此实现中按像素裁剪，边缘不完整文字行会整行隐藏；桌面端边缘不完整图片也整项隐藏，避免滑动每个像素都创建新裁剪纹理。它不是完整 GPU scissor 实现。长文本请在模组侧按列宽换行。嵌套容器的触摸手势由更深层命中区域接管，外层滑轨除外；滚轮仍由先命中的外层接管。

`image_cache_stats()` 返回：估算缓存字节、预算字节、描述符数量、累计淘汰次数。

## 图标文件夹

- 原生模组窗口收起后统一显示为方形图标；没有图片的图标显示 compact_label 或 M。
- 拖动一个图标到另一图标或已有文件夹上，重叠停留至少 350 ms，再松手合并。
- 文件夹显示最多 4 个小图标预览；点击展开成员网格，点击成员打开其窗口。
- 从展开网格拖动成员到面板外，松手移出文件夹；成员不足 2 个时解除分组。
- 点击文件夹外收起；超过 9 个成员使用网格顶部左右按钮翻页。
- 分组及文件夹位置保存在加载器私有目录 gui_layout.json。缺失/暂时禁用的模组保留记录；少于 2 个可用成员时不显示文件夹。图标被分组且窗口收起时，不执行该窗口 on_gui。
- 模组若自己通过其他绘制系统创建悬浮按钮，不会自动纳入文件夹。

## 测试与限制

测试使用生产实现，覆盖视口边界、拖动/滑轨偏移限幅、释放误点击取消、容器结束恢复、文件夹成员关系与配置保存读取、缓存淘汰与当前帧保护、裁剪资源销毁和每帧上传次数。

没有连接游戏实机；不能保证特定设备的帧率、触摸穿透、ABI 或驱动行为。请先安装加载器并导入 examples 下的三个测试模组，确认拖动、图标合并、成员移出和重进游戏分组恢复，再将合成表改用 begin_scroll。升级加载器不会自动把旧合成表的上一页/下一页转换成滑动列表。

主机测试命令：

```sh
cmake -S . -B build/tests -DLUALOADER_BUILD_GUI_TESTS=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build/tests -j 3
ctest --test-dir build/tests --output-on-failure
```

## 已合并的 UI 修复

- 回调结束先在录制状态中收尾滚动容器，再清空上下文。
- 保存布局失败保留待保存状态，间隔五秒重试；替换文件时保留旧文件备份并尝试回滚。
- 首次 set_pos 尊重已保存的位置；卸载时清理位置恢复标记。
- 滑轨拖动按滑块实际行程换算；嵌套滚动在按下时由更深层命中区域接管（外层滑轨除外）。滚轮仍由先命中的外层接管。
- text/text_wrapped 支持可选颜色，颜色可用数组或 r/g/b/a；默认仍用主题颜色，部分控件标签也遵循主题。
- 点击文件夹外关闭时清理成员手势。

大 PNG 解码仍为同步操作，预算仍是估算，边缘文字/桌面图片的裁剪策略保持不变。
